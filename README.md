# ROBOTRAC Laravel Base UI

Laravel 12 + Blade base UI for ROBOTRAC Tractor India Private Limited.

## Included
- Reusable Blade layout
- Navbar, footer, section-heading and button components
- Responsive homepage
- About, Products and Contact routes
- Supplied ROBOTRAC logo and vehicle assets
- Mobile navigation
- Scroll reveal animations
- Clean responsive CSS
- Ready for database-driven Products, Enquiries, Dealers, Gallery and Admin modules

## Setup
composer install
cp .env.example .env
php artisan key:generate
php artisan serve

Open http://127.0.0.1:8000

Public pages intentionally exclude personal Aadhaar/PAN/family information.
